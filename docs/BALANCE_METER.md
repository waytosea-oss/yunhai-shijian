# 算力码表接入说明

算力码表是云海诗鉴的第二条信息轴：云图展示自然系统的变化，码表展示 AI 系统的可用余量。它不是厂商账单页的替代品，而是一个适合常亮屏幕的聚合视图。

## 最简单的接入

1. 由你信任的本地脚本或服务收集使用量。
2. 把结果转换成 `docs/API.md` 定义的 JSON。
3. 写入一个本地文件，例如 `/var/tmp/yunhai-balance.json`。
4. 启动服务时指定：

```bash
YUNHAI_BALANCE_FILE=/var/tmp/yunhai-balance.json npm start
```

网页只会读取这个聚合文件。采集器如何登录服务商、如何计算额度窗口，不属于本仓库的安全边界。

## `pct` 到底表示什么

`pct` 统一表示**剩余百分比**。多个窗口同时存在时，主屏采用剩余值最低的窗口作为当前瓶颈；展开页会显示全部窗口。

例如：

- 5 小时窗口剩余 84%；
- 每周窗口剩余 42%；
- 主屏显示 42%，因为它先限制后续工作。

## 隐私原则

建议只输出：

- 剩余百分比；
- 窗口刷新时间；
- 聚合 Token 数；
- 已匿名化或经本人确认可公开的项目名称。

绝对不要输出：

- API Key、Session Token、Cookie；
- 账号密码、邮箱和付款信息；
- 完整提示词、对话正文或客户文件名；
- 能反推出个人身份的内部项目数据。

公开截图前请切换到 `demo/balance.json`，避免无意展示真实账户状态。

## 接入其他工具

前端当前为 Codex 和 Claude 保留了两个固定视觉通道，以维持紧凑排版。若要增加其他工具，建议先扩展数据契约和响应式布局，并为未知工具提供中性色，而不是复用现有品牌色。
