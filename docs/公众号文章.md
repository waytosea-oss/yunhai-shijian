# 我把一块闲置屏幕，变成了“会读云图的 AI 气象氛围屏”

很多人见过卫星云图。

它通常出现在天气预报里：一团云、一条路径、几个箭头。看完，我们知道明天带不带伞，然后关掉页面。

我一直觉得，这有点可惜。

云图其实是一张不断书写的地球手稿。海面上的旋转、长江口的水汽、北方推进的冷云带，都在缓慢移动。只看一张图，它像壁纸；把连续几张图放在一起，它才开始讲述时间。

于是，我做了“云海诗鉴”。

![云海诗鉴主屏](images/01-main-screen.png)

## 它先看云，再写诗

这套系统不是把天气关键词随机塞进古诗模板。

每天，它会读取按时间排列的多帧云图，比较云带的位置、形态与组织变化：哪里在增强，哪里在东移，哪里只是看上去像一个旋涡。然后再把权威气象快讯放在旁边核对。

这一步很重要。AI 可以从图上观察到旋转云系，却不能因为“长得像台风”就擅自给它起名字。正式名称、编号、强度和路径，必须来自权威气象机构。

确认完事实，它才写诗：四行，每行五个字。

不是一段解释，不是一篇报告，而是一枚落在云海上的小诗签。

## 为什么一定要竖排

我把诗签做得很窄，因为屏幕的主角仍然是云图。

两列文字顶部对齐，右列多收第三句的前两个字，左列因此空出一段，刚好落下一方小印。文字完全不透明，底色半透明；看得清诗，又不把云遮死。

诗签可以拖动。今天东南海面有重要云系，就把诗签挪到左上；明天北方云带更值得看，再把它放回右下。它会记住位置。

字体也可以在志莽行书与马善政楷书之间切换。启功体等授权不明确的字体没有放进开源仓库，这件事必须克制。

![字体切换](images/05-font-switch.png)

## 点一下，诗背后的判断就展开了

屏幕上的四句诗很轻，但它背后的分析不应该消失。

单击诗签，完整判读页会展开：主要天气现象、移动趋势、对上海与长江口的影响、多帧判断依据、置信度，以及一段把天气与当日国际风云轻轻相连的文字。

![云图气象判读](images/02-weather-analysis.png)

诗负责留白，判读负责把依据说清楚。两者不能混在一起。

## 最有意思的，是左上角那只“算力码表”

云图记录自然界的能量，算力码表记录 AI 的能量。

左上角两条很小的仪表，显示 Codex 与 Claude 当前最紧张的额度窗口和刷新倒计时。点开以后，还能看到不同窗口、今日与本月 Token、最近 14 天趋势，以及算力花在了哪些项目上。

![AI 算力码表](images/03-balance-meter.png)

这不是为了炫耀消耗，而是让“AI 正在工作”从一句抽象的话，变成可以观察、可以安排的节奏。什么时候适合做一次重分析，什么时候应该让系统安静刷新，码表一眼就能告诉我。

它只读取聚合后的 JSON，不接触密码、Cookie 或原始 API Token。公开演示中的所有数字也都是虚构的。

## 一套界面，多种终端

我最初把它放在小度智能音箱上，当作常亮屏保。现在开源版同时提供：

- 浏览器全屏版，适合 Mac、Windows、Linux 和 iOS；
- Android 横屏应用；
- Android 系统 `DreamService` 屏保；
- 可接入自有云图、诗签和算力数据的零依赖本地服务。

仓库默认使用一张合成的卫星风格图片，不附带任何受限制的实时云图，也不包含私人余额数据。你可以先离线体验，再决定接入哪一家合法数据源。

## 为什么开源

一开始我也想过把它做成产品。但真正让我着迷的不是收费入口，而是这个想法还能长出多少不同版本：

有人可能关注南海台风，有人想看青藏高原水汽，有人只想让办公室的一块旧屏幕安静地显示故乡上空的云。有人会接入别的模型，有人会写出完全不同的诗。

把接口和终端打开，比把它关在一个 App 里更符合这件事的气质。

项目已经以 Apache License 2.0 开源：

**GitHub：<https://github.com/waytosea-oss/yunhai-shijian>**

三分钟就能运行默认演示。真正接入实时气象数据前，请先确认图片授权，并记住：AI 判读是辅助观察和文化表达，不是官方天气预报或灾害预警。

云在天上走，诗在屏上落，算力在左上角慢慢回满。

这就是云海诗鉴。
