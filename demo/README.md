# 演示数据说明

这个目录只用于让仓库在没有外部服务时立即运行。

- `cloud-synthetic.jpg`：AI 生成的东亚与西北太平洋卫星风格合成图，不对应真实日期、卫星、台风或天气系统。
- `poem.json`：人工整理的四行五言演示诗与虚构判读文字。
- `balance.json`：虚构的 Codex / Claude 额度窗口、Token 趋势和项目名称。

合成云图生成要求为：东亚与西北太平洋的真彩卫星风格画面，包含多层云带和远洋松散旋转云系，不含机构标识、水印、文字或时间戳，并明确不模拟任何真实时刻。

公开截图和测试默认使用这些文件。接入真实数据时，请通过环境变量指向部署目录，不要覆盖演示文件，也不要把私人余额或授权不明的气象图片提交到仓库。
